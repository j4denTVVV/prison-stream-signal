# Prison Stream Signal

🔒 LOVABLE PROMPT — PRISON STREAM

Build a highly polished, cinematic website for PRISON STREAM, a newly announced creator/streaming project launching in Autumn 2026.

The exact launch date has NOT been announced yet.

The identities, roles, terminology and full concept surrounding the people participating in Prison Stream have also not necessarily been revealed yet.

The website should therefore create mystery, anticipation and speculation rather than presenting unconfirmed information as fact.

CORE CONCEPT

The website should feel like visitors have discovered a mysterious underground prison broadcasting system.

The visual identity should be:

Dark

Industrial

Rusted

Cinematic

Mysterious

Premium

Slightly unsettling

Modern

Think:

Rusted metal × concrete × prison architecture × CCTV × classified documents × underground broadcast station × streaming culture

Do NOT make this look like a cheap Halloween website.

Do NOT make it cartoonish.

Do NOT overuse obvious prison clichés.

The prison theme should feel like a real world, mysterious brand universe.

IMPORTANT — DON'T INVENT INFORMATION

The following information is currently unknown/unconfirmed:

Exact launch date

Exact launch time

Final creator roster

What participants will officially be called

Number of participants

Full format of the project

Exact events

Full stream schedule

Additional people involved

Future announcements

Therefore, DO NOT invent these details.

Use placeholders and mystery language where information has not been announced.

For example, instead of saying:

“37 inmates are currently inside.”

Use:

OCCUPANTS: UNKNOWN

or:

ROSTER STATUS: CLASSIFIED

Instead of:

“Meet the inmates.”

Use:

WHO'S INSIDE?

or:

THE ROSTER

or:

IDENTITIES CLASSIFIED

This allows the website to evolve as announcements happen.

PRISON STREAM

When the official date is eventually known, the website should be structured so the placeholder can easily be replaced with a real countdown.

HERO CTA

Secondary button:

WATCH THE TRAILER

The “Enter the Prison” button should transition into the main website with a cinematic door/security-system animation.

SOUND

If implementing sound, keep it:

Muted by default

Optional

Easily disabled

Possible sounds:

Low industrial hum

Distant metal doors

CCTV static

Radio interference

Mechanical locks

RESPONSIVE DESIGN

Make the entire experience excellent on:

Desktop

Laptop

Tablet

Mobile

The mobile version should feel like a classified security terminal on a phone, rather than simply shrinking the desktop website.

IMPORTANT CONTENT ARCHITECTURE

Build the site so information can easily be updated later.

The following should be configurable:

Launch date

Launch countdown

Launch status

Creator roster

Creator names

Creator profiles

Creator images

Creator social links

Stream links

Announcements

Polls

Events

Do not hard-code assumptions about the project.

The website is being launched while information is still being revealed, so the design should make unknown information feel intentional.

OVERALL EXPERIENCE

The website should make someone feel like they have discovered something they aren't supposed to know about yet.

The visitor should leave thinking:

What is Prison Stream?

Who's actually inside?

When does it start?

What happens when the gates open?

Who are they going to announce next?

The website itself should become part of the hype surrounding the launch.

Mystery is more important than filling every section with information.
